# Youcode Sprint 1 - Brief 2

A sprint project from the Youcode curriculum demonstrating web development fundamentals in Brief 2.

## 📋 Description

This project is part of the Youcode Sprint 1 curriculum, Brief 2. It focuses on building a practical web application using modern development practices and technologies.

## 🏗️ Technology Stack

- **Frontend**: HTML5, CSS3, JavaScript
- **Backend**: PHP/Node.js
- **Database**: MySQL/SQLite

## 🚀 Features

- Responsive web design
- Interactive user interface
- Database integration
- Form validation
- User authentication
- Clean code structure

## 📦 Installation

### Prerequisites
- PHP 7.4+ or Node.js 12+
- npm/Composer
- Modern web browser

### Setup Instructions

1. **Clone the repository**
   ```bash
   git clone https://github.com/Lahcen-akdime/Youcode-Sprint-1-bref2.git
   cd Youcode-Sprint-1-bref2
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   composer install
   ```

3. **Configure environment**
   ```bash
   cp .env.example .env
   ```

4. **Setup database** (if applicable)
   ```bash
   npm run db:setup
   ```

5. **Start development server**
   ```bash
   npm start
   # or
   php -S localhost:8000
   ```
